## Task 3 - Real Estate Market Trends 🏠
**Dataset:** USA Real Estate Dataset (2.2M+ entries)

### Dashboard Includes:
- KPI Cards (Avg Price, Total Properties, Avg House Size)
- Bar Chart (Average Price by State)
- USA Map (Property Locations)
- Pie Chart (Property Status)
- Scatter Plot (Price vs House Size)
